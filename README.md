# KIVILCIM

Kıvılcım adlı tamircinin yüzen adalar dünyasında geçen, tarayıcıda oynanan 3D bir macera oyunu.
Three.js ile yazılmıştır; kurulum gerektirmez.

## Nasıl oynanır

- Gökyüzündeki dört adadan **dişli** topla.
- Dört dişli tamamlanınca saat kulesinin tepesine tırman ve saati çalıştır.
- **ÇEKİÇ** ile dişli platform üret, robot kuşları sersemlet.
- Robot kuşlara çarparsan son adadan devam edersin.

### Kontroller

| Cihaz | Hareket | Zıpla | Çekiç |
|---|---|---|---|
| Telefon | Ekranın sol yarısını kaydır | ZIPLA düğmesi | ÇEKİÇ düğmesi |
| Bilgisayar | WASD / ok tuşları | Boşluk | F |

## Telefonda oynamak (GitHub Pages)

1. Bu klasörü bir GitHub deposuna yükle.
2. Depo ayarlarında **Settings → Pages** bölümüne gir.
3. **Source** olarak `Deploy from a branch` seç, branch olarak `main` ve klasör olarak `/ (root)` seç, kaydet.
4. Birkaç dakika sonra `https://<kullanici-adin>.github.io/<depo-adi>/` adresi açılır. Telefonda bu adresi aç.
